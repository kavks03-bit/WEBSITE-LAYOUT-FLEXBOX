# Website Layout Using Flexbox with Semantic HTML

## Project Description
This project is a Goa Travel Agency website developed using HTML5 and CSS. It demonstrates how to create a structured and responsive website using semantic HTML elements and the CSS Flexbox layout.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox

## Features
- Header with website title and tagline
- Navigation bar with links to different pages
- Sidebar for additional navigation
- Main content area with travel information
- Travel package and beach information cards
- Contact page with an enquiry form
- Responsive layout for different screen sizes
- Semantic HTML elements for better structure

## HTML Elements Used
- `<header>` – Defines the website header.
- `<nav>` – Contains navigation links.
- `<main>` – Contains the main content.
- `<aside>` – Displays sidebar content.
- `<section>` – Groups related content.
- `<article>` – Represents individual content cards.
- `<footer>` – Displays footer information.
- `<a>` – Links to other pages.

## CSS Concepts Used
- Flexbox for page layout
- Background colors and text styling
- Padding and margins
- Borders and border radius
- Hover effects
- Media queries for responsive design

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Use the navigation links to explore the different pages.

## Learning Outcome
This project helps beginners understand semantic HTML, CSS Flexbox, webpage navigation, styling, and responsive website design.
